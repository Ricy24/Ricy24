# 🧠 Proyecto principal

## 🩵 Senti

**Senti** es una plataforma de bienestar emocional que combina **Inteligencia Artificial y profesionales de la psicología**.

El proyecto busca utilizar la tecnología como herramienta de apoyo para comprender mejor las necesidades de los usuarios y facilitar el trabajo de los profesionales.

### Componentes

* ⚙️ **Backend (Django REST)** — [`backend`](https://github.com/Ricy24/backend)
* 🌐 **Frontend (React)** — [`frontendsenti`](https://github.com/Ricy24/frontendsenti)

### Algunas capacidades

* 🤖 Asistencia basada en IA
* 🧠 Análisis de patrones emocionales
* 👥 Gestión de usuarios y profesionales
* 🔐 Autenticación e integración con Google
* 📊 Análisis y seguimiento de información
* 📩 Sistemas de comunicación y notificaciones
* ☁️ Almacenamiento y servicios cloud
* 🐳 Arquitectura basada en contenedores
* 🔎 SEO y optimización de rendimiento

### Stack

`Django` · `Next.js` · `Docker` · `PostgreSQL` · `OpenAI` · `Hugging Face` · `Cloudflare R2`

> **Objetivo:** construir tecnología que complemente el trabajo humano, no que lo reemplace.

# 💰 LifeOS

**LifeOS** es una plataforma de gestión financiera personal que estoy desarrollando para explorar problemas de **finanzas, predicción, simulación y optimización**.

El proyecto está diseñado alrededor de una arquitectura **offline-first**, con un motor financiero determinístico y sincronización con backend.

📦 **Repositorio:** [`lifeos`](https://github.com/Ricy24/lifeos)

### Componentes principales

* 💵 Motor financiero determinístico
* 📈 Forecasting de ingresos
* 🔮 Simulación de escenarios
* 🎯 Gestión y planificación de objetivos
* ⚙️ Optimización financiera
* 📱 Aplicación Android
* 🔄 Sincronización offline/online
* 🤖 Integración con IA
* 📲 Integración con Telegram
* 🐳 Backend contenerizado

### Stack

`Kotlin` · `Jetpack Compose` · `FastAPI` · `Python` · `PostgreSQL` · `Docker` · `Oracle Cloud`

# 🚰 PlomApp

**PlomApp** es una plataforma de gestión de servicios de plomería que conecta **clientes con técnicos**, compuesta por app móvil, frontend web y API.

### Componentes

* 📱 **App Android** — [`android_plomaap`](https://github.com/Ricy24/android_plomaap) · Kotlin
* 🌐 **Frontend web** — [`plomaap_react_estable`](https://github.com/Ricy24/plomaap_react_estable) · React 19 + Vite
* ⚙️ **API** — [`plomaap_django`](https://github.com/Ricy24/plomaap_django) · Django + JWT
* 🗄️ **Versión web completa** — [`plomaap_codigo`](https://github.com/Ricy24/plomaap_codigo)

### Capacidades

* 👤 Registro, login y roles (cliente / técnico / administrador)
* 📋 Solicitud, asignación y seguimiento de servicios
* 🧑‍🔧 Paneles para técnico y administrador
* 📡 API REST documentada con **Swagger**

### Stack

`Kotlin` · `Android` · `React` · `Django` · `PostgreSQL` · `Flask` · `Docker`
